# Superstore Sales & Profit Analysis – Power BI

## Project Overview
This project presents an interactive Power BI dashboard built using the Superstore dataset. It analyzes sales, profit, quantity sold, profit margin, customer segments, regional performance, and monthly sales trends.

The dashboard helps users explore business performance through interactive slicers, KPI cards, and different visualizations.

## Tools and Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- CSV Dataset

## Dataset Columns
- Order Date
- Region
- State
- Category
- Sub-Category
- Segment
- Sales
- Profit
- Quantity

## Dashboard Features

### Interactive Filters
The dashboard includes slicers for:
- Order Date
- Region
- State
- Category
- Sub-Category
- Segment

### Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Quantity Sold
- Total Orders
- Profit Margin (%)
- Average Sales

### Visualizations
1. **Sales by Category** – Compares sales across product categories.
2. **Profit by Region** – Compares profitability across regions.
3. **Monthly Sales Trend** – Shows sales trends over time.
4. **Profit by Sub-Category** – Uses a treemap to compare sub-category performance.
5. **Sales by Customer Segment** – Shows the distribution of sales across customer segments.
6. **Sales vs Profit by Category** – Compares sales and profit across categories.

## Key Objectives
- Analyze overall sales and profit performance.
- Compare sales across product categories and customer segments.
- Identify regional differences in profitability.
- Understand monthly sales trends.
- Explore performance across product sub-categories.
- Use DAX measures to calculate important business KPIs.

- Data import and preparation

## Conclusion
This project demonstrates how Power BI can be used to transform sales data into an interactive dashboard. It provides a clear view of business performance and supports data-driven decision-making.
